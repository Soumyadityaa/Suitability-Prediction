The cultivation of high-value spices such as Clove, Black Pepper, and Small Cardamom presents significant economic opportunities. However, strict microclimatic requirements and a severe lack of localized, historical cultivation data expose farmers to catastrophic financial risks. To resolve this data scarcity bottleneck, we introduce a "Literature-Based Data Construction" methodology. We synthesized a structurally balanced dataset of 89,999 instances by mathematically bounding 14 agronomic parameters (including Soil pH, NPK levels, Temperature, and Elevation) using thresholds extracted from peer-reviewed literature. Evaluating eight supervised machine learning algorithms revealed that ensemble architectures best handle these complex biological thresholds. Extreme Gradient Boosting (XGBoost) emerged as the superior model, achieving a baseline accuracy of 86.69%, which improved to a peak accuracy of 88.50% following rigorous hyperparameter optimization. Tuned specifically to minimize false-positive predictions, the resulting framework acts as an algorithmic economic safeguard, allowing for precise "Suitability Gap" analysis in non-traditional growing regions.
